# معماری داده و برنامه اجرایی نسخه بعدی — همیار ناظر

## موجودیت‌های اصلی

1. **ProjectEntity** (به‌روزشده)
   - floorsCount از روی شالوده
   - effectiveArea
   - suggestedBuildingGroup + selectedBuildingGroup
   - groupChangedByUser برای تاریخچه

2. **InspectionVisitEntity**
   - تاریخ شمسی مستقل
   - ساعت اختیاری
   - مرحله اجرا

3. **ChecklistItemEntity**
   - شناسه ثابت (CL-xxx)
   - فیلد isGasRelated
   - پشتیبانی از بند اختصاصی ناظر

4. **InspectionItemResultEntity**
   - وضعیت‌های کامل: تأیید، عدم تأیید، نیازمند اصلاح، قابل بررسی نیست، نامرتبط، در این مرحله اجرا نشده

5. **ReportVersionEntity**
   - نسخه‌بندی کامل
   - لحن گزارش
   - فیلد اختیاری شماره ثبت شهرداری
   - includeGas

## Migration
- نسخه پایگاه داده افزایش می‌یابد.
- از Migration امن استفاده شود (نه fallbackToDestructiveMigration).
- داده‌های قبلی حفظ می‌شوند.

## صفحات اولویت‌دار برای پیاده‌سازی بعدی
1. Landing Page (معرفی سازنده و شرکت)
2. فرم تعریف پروژه با Dropdown طبقات و محاسبه گروه
3. ثبت بازدید با تقویم شمسی
4. نمایش و ثبت وضعیت چک‌لیست
5. تولید و نسخه‌بندی گزارش

## گروه ساختمان (مبحث ۲)
- الف: ۱–۲ طبقه یا تا ۶۰۰ مترمربع
- ب: ۳–۵ طبقه یا ۶۰۱–۲۰۰۰ مترمربع
- ج: ۶–۱۰ طبقه یا ۲۰۰۱–۵۰۰۰ مترمربع
- د: بیش از ۱۰ طبقه یا بیش از ۵۰۰۰ مترمربع
- در صورت تعارض، به ناظر نمایش داده شود.

این ساختار آماده پیاده‌سازی است.
